# ANTIGRAVITY CLI — WORK INSTRUCTIONS

# GLOBAL RULES — APPLY TO EVERY TASK

## Before writing any code
Inspect only the onboarding-related files.
Do not read the entire repository.
First list the relevant files and their purpose.
Then propose the smallest possible change.
Do not print full file contents; summarize only what is needed.

## While implementing
1. Follow the existing folder structure, naming conventions, styling
   approach, state-management pattern, and API structure.
2. Make the smallest change needed to complete the task.
3. Do not refactor unrelated code.
4. Do not rename existing files, functions, routes, components, or APIs
   unless explicitly instructed.
5. Do not install dependencies unless absolutely necessary.
6. Preserve existing functionality.

## Error prevention
1. Check imports, types, props, and route paths before finishing.
2. Handle loading, empty, error, and success states.
3. Validate user input.
4. Ensure mobile responsiveness.
5. Run lint/build commands available in the project.
6. Do not mark a task complete if there are build, type, lint, or runtime
   errors.

## After every task
Report:
1. Existing code found and reused.
2. New files created, with reason.
3. Files modified.
4. Schema/database changes, if any.
5. Build/lint/test results.
6. Remaining risks or manual testing steps.
